Project Documentation: Repo Onboarding Agent 🚀

1. Project Overview

  • Description: This project is an automated documentation agent designed to analyze Git repositories. It clones a given repository, builds an Abstract Syntax Tree (AST) to understand the code structure, and utilizes a dual Large Language Model (LLM) architecture to perform detailed analysis of functions and classes. The final output is a comprehensive, human-readable documentation report. The system features a web-based user interface built with Streamlit for user interaction and presenting the results.

  • Key Features:

    • Automated Git Repository Cloning and File Processing.
    • Deep Code Analysis via Abstract Syntax Tree (AST) Generation.
    • LLM-Powered Extraction of Function, Class, and Method Documentation.
    • Automated Report Generation in Markdown format.
    • Secure User and API Key Management.
    • Interactive Streamlit-based Web Frontend.

  • Tech Stack: Python, Streamlit, LangChain, Google Gemini API, OpenAI API, Ollama, GitPython, PyMongo, Pydantic, NetworkX, Matplotlib
